# 카드뉴스 출력 기준 v1.0 (파이프라인 전체 기준)

미리보기가 승인 화면에 올라오기 전에 **모든 세트가 이 기준을 자동으로 통과**해야 한다.
기준 목록의 원본은 `src/qa/output_standard.py`의 `RULES`이고, 아래 표는 그것을 사람이 읽기 쉽게 옮긴 것이다
(`tests/test_output_standard.py`가 두 곳의 규칙 id가 같은지 검사한다).

- **block**: 승인·게시가 막힌다(대시보드가 거절한다).
- **warn**: 승인 화면의 "자동 점검" 패널에 빨간 안내로 뜬다. 승인은 가능하다.
- 점검은 AI를 호출하지 않으므로 비용이 없다. 렌더러가 남긴 `layout.json`, `script.json`, `caption.txt`,
  `background.png`, 카드 파일 이름만 읽는다.

| id | 심각도 | 기준 | 지키는 방법(코드) |
|---|---|---|---|
| S1-structure | block | 표지 1 + 내용 3~6 + CTA 1, 모든 카드 이미지 존재 | `script_assembler`, `check_output` |
| S2-typography | warn | 내용 카드 제목 56px·본문 40px 동일(본문이 길 때만 줄임) | `design_renderer.TITLE_FONT_SIZE/BODY_FONT_SIZE`, `layout.json` |
| S3-position | block | 영상 없는 카드 본문 패널 `TEXT_BODY_TOP`, 영상 카드 `BODY_TOP`(영상 56% 바로 아래) | `design_renderer`, `tests/test_body_grid.py` |
| S4-video-evidence | block | 영상 카드는 자막 검증·움직임 확인·채널명·영상 파일 모두 있음 | `youtube_fetcher.find_verified_video_for_slide`, `pipeline` |
| S5-no-unverified-media | block | 검증 기록 없는 영상(스톡 포함)은 금지, 없으면 문장 카드 | `STOCK_VIDEO_FALLBACK` 기본 off, 자막 없는 영상 거부 |
| S6-cover-figure | warn | 표지 제목의 숫자는 대상이 붙은 구절("100만 대 이상의 로봇")이어야 하고 "80%"처럼 숫자만 있으면 안 됨 | `script_assembler.has_complete_figure`, `_lead_figure_phrase` |
| S7-caption | block | 온전한 첫 줄 + 출처 줄 | `design_renderer._generate_caption`, `caption_guard`, `preview_audit` |
| S8-stat-language | warn | 수치 상자 표기는 본문과 같은 언어 | `script_assembler._localized_stat` |
| S9-background | warn | 본문 카드 배경 평균 밝기 ≤ 125/255 | `design_renderer._apply_background` |
| S10-source | block | 출처 정보 기록 → 카드 하단·캡션에 표시 | `source_note`, `_draw_source_footer` |

## 문체
카드와 캡션에는 **문장 끝 마침표를 쓰지 않는다**. 한 줄에 문장이 이어지면 줄을 바꿔 나눈다.
소수점(3.5), 날짜(2026.10.22), 도메인(aitimes.com), 말줄임(...)은 그대로 둔다(`src/qa/text_style.py`).

## 릴스(9:16 영상)
카드 세트를 세로 영상으로 바꿀 수 있다(`python scripts/make_reel.py <큐 번호>`, `src/agents/reel_builder.py`). AI 호출과 비용이 없고
**자동으로 게시하지 않는다**(게시는 사람이 승인한 뒤에만). 흐린 배경 + 카드 + 느린 확대 + 진행 막대, 슬라이드마다 글 읽는 시간만큼 머무름,
전체 60초 이내. 음악은 넣지 않는다(게시 API로는 라이선스 음원을 붙일 수 없고 무단 음원은 계정 위험이 있다). 점검: 1080×1920, 3~90초, 100MB 이하.

## 영상 정책 (한 줄 요약)
영상은 **자막으로 내용이 맞고 + 화면이 실제로 움직이고 + 광고/투자 선동이 아닐 때만** 붙인다.
하나라도 못 지키면 그 카드는 영상 없이 **문장 카드**로 나간다(대체 영상 없음). 영상 카드 비율은 56:44.

**사용 허락(2026-10-31 추가):** 출처 표기는 허락이 아니므로, 영상은 쓰는 쪽이 재사용을 허락했음이 분명할 때만 쓴다
(`youtube_fetcher.video_use_permitted`). 영상의 라이선스가 크리에이티브 커먼즈이거나, `.env`의 `VIDEO_ALLOWED_CHANNELS`에
직접 적어 둔 채널(허락받았거나 공식 배포 채널)일 때만 통과한다. 라이선스를 알 수 없으면 쓰지 않는다. 이 확인은 자막 요청보다 먼저 하므로
허락 없는 영상에는 자막 요청도 보내지 않는다. 그 밖의 경우는 문장 카드로 나간다.

## 이 기준을 바꾸는 방법
1. `src/qa/output_standard.py`의 `RULES`와 `check_output`을 먼저 고친다.
2. 이 문서의 표를 같이 고친다(테스트가 id 불일치를 잡는다).
3. 렌더링 코드를 고치고 `tests/test_output_standard.py`, `tests/test_body_grid.py`가 통과하는지 확인한다.
새 규칙을 코드에 먼저 넣고 기준에 안 올리면, 같은 문제가 다시 눈으로만 발견된다.

## 수집 기준 (주제 범위 B)
- 후보는 **AI 및 AI 인접** 기사만 쓴다. 오늘 해당 기사가 모자라면 **모자란 대로** 보여주고, 다른 주제로 채우지 않는다.
- 대시보드 문구는 실제 숫자를 그대로 적는다: "N개 추가 (요청 M개) · 오늘 후보: AI x, AI 인접 y, 그 외 z — 제외: …".
  제외 사유는 `logs/collection.log`에 남는다.
- 신선도 2일 이내, 본문(전문) 500자 이상, 광고·딜 기사 제외.
- **보안·해킹 기사는 AI가 이야기에 들어 있을 때만 AI 뉴스다**(`src/qa/security_scope.py`). 공격자가 AI를 썼거나,
  AI가 취약점을 찾았거나, AI 도구 자체가 뚫린 기사는 범위 안이고, AI 없이 거래소·금융권이 털린 일반 사고는 범위 밖이다.
  판단은 제목만 보지 않고 제목·요약에 AI가 있으면 통과, 없으면 본문에서 서로 다른 AI 용어가 2개 이상 나와야 한다.
  본문에 "클라우드"·"반도체" 같은 일반 단어가 있다고 AI 인접이 되지는 않는다. 제외한 보안 기사 수는 수집 결과 문구에 따로 적는다.
- **후보 선택 신호(참고용)**: 후보마다 사람들이 많이 찾는 분야(규제·정책, 투자·돈, 일자리, 환경·전력, 보안·개인정보, 교육·의료;
  `src/qa/topic_category.py`)와 오늘의 한국 검색 키워드(`src/agents/trend_signal.py`, 구글 트렌드 RSS)를 표시해서 선택 AI에게
  보여 준다. 이 신호로 기사를 통과시키지는 않는다(AI 범위·최신성·근거 검사가 먼저). 읽지 못하면 표시 없이 진행한다.
  분야별 반응은 `python scripts/growth_snapshot.py`가 게시물 도달과 묶어서 보여 주며, 표본이 쌓이기 전에는 가중치를 정하지 않는다.
- 한국 보안 전문 매체(데일리시큐)를 수집 대상에 포함한다. 보도자료·행사 기사가 섞이므로 구체적 대상·수치 검사가 걸러낸다.

## 생성 기준
- 숫자·고유명사 주장은 원문 근거와 결정적 검사를 통과해야 한다(표기 코퍼스 `tests/test_number_format_corpus.py`, 새 표기는 행 추가).
- **사후에 사람이 고치지 않도록 파이프라인이 먼저 막는 규칙**(`src/qa/card_rules.py`, 모델 호출 없음, 비용 0): 실제 세트(#28·#33·#35)에서
  손으로 고쳤던 네 가지를 규칙으로 옮겼다.
  1. 기사 제목에 수치가 있으면 **표지가 그 수치를 내세운다**(요금제 가격 "200달러" 대신 제목의 "최대 2배"). 제목에서 "수치 + 대상" 구절을
     잘라 쓰며, 구절이 기준을 못 채우면 그대로 둔다.
  2. **캡션의 첫 줄과 핵심 줄에 카드의 수치가 들어간다.** 빠졌으면 카드의 검증된 문장으로 핵심 줄을 다시 만든다(사후 감사 단계).
  3. **마지막 장 칩 라벨은 그 수치가 무엇인지 말한다.** 소제목에 수치가 있으면 소제목에서 수치를 뺀 말, 없으면 그 카드의 수치 라벨.
  4. **답 없는 마지막 장 제목은 쓰지 않는다**("당신은 어떻게 생각하나요", "이 모델의 특징은" -> "핵심만 다시 보면").
- **원문이 단서를 단 내용은 카드에서 단정하지 않는다**(`src/qa/hedge_guard.py`). 근거 문장에 "정황·추정·의혹·의심·단정·확인되지 않았다"가
  있는데 카드 문장이 공격·해킹·유출·배후를 같은 단서 없이 사실로 쓰면 `CLAIM_HEDGE_DROPPED`로 거절하고 다시 쓰게 한다.
  예: "북한 IP가 탐지됐으나 북한 해킹으로 단정하기 어렵다"를 "북한이 해킹했다"로 쓸 수 없다.
- 편집 점수: 평균 ≥ 7.0 이고 각 항목 ≥ 7.0 (판정 gpt-4o-mini, temperature 0). 루브릭은 구체적 수치·대상을 보상하고 과장 피드백을 금지한다.
- 1세트 비용 상한 `$0.20`(`DEFAULT_MAX_RUN_COST_USD`). 상한에 걸리면 `RUN_BUDGET_EXCEEDED`로 표시하고 이미 나간 비용은 복구되지 않는다.
- 배경은 어두운 관련 이미지를 우선한다(밝은 스타일은 명시했을 때만).

## 자동 점검 vs 사람이 볼 것
| 자동(코드가 막거나 경고) | 사람이 승인 화면에서 볼 것 |
|---|---|
| S1~S10 전부, 숫자 근거, 캡션 온전성, 비용 상한 | 주제가 오늘 올릴 만한지, 영상 내용이 카드 문장과 맞는지, 배경 사진이 어색하지 않은지 |

## 잠정값 (측정 후 확정)
- 편집 점수 임계 7.0, `EDITORIAL_SCORE_RETRIES`(기본 1), 배경 밝기 125 — 회귀 측정 결과로 확정한다.
- 목표: 성공률 ≥ 80%, 세트당 비용 ≤ $0.12.

## 회귀 측정 규칙
- `scripts/regression_run.py`는 큰 변경 뒤에만, 1회에 약 $1 이하, 필요하면 일부 기사만 돌린다.
- OpenAI 잔액이 없을 때는 돌리지 않는다(Gemini 대체 호출은 단가 미집계라 비용이 보이지 않는다).
- 테스트(`pytest`)는 AI/네트워크를 호출하지 않아야 한다. 호출이 생기면 시임을 패치한다.
